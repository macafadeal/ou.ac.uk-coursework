# Web Server Overview

We have already seen that a web server is composed of a consortium of disparate parts all working together to support connection to and from web resources. For Week 19 we have primarily focused on developing Python programming skills so that we are able to create functionality for a web application.

Now that we have a basic understanding of the building blocks used in the construction of a web application, we will work on setting up a web server to test some of these building blocks a little further. Rather than implement all of the functionality of a web server, we will leverage the functionality built in to our programming language.

For the most basic version of this, we have already seen that we can start a web server instance by issuing a console command instructing an installed Python interpreter to do so with very few arguments.

This section, however, will focus on the skills discussed in Week 19 related to the development of a basic web server in Python with a little more customisation than is offered by the pre-built module.
