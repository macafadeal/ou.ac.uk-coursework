# Environment Overview

Throughout the materials in Week 19, we have discussed a number of different concepts in relation to the components of a web server. In addition, we have explored the ways in which we can instruct the server to perform the functions we require through an application using a programming language; Python.

The activities contained within this workbook will help you to familiarise yourself with the fundamentals of this language before helping you develop the necessary skills to implement a functional web server application.

To implement a python script you will need access to an editor and an interpreter. In previous weeks of this module (weeks 10-13), you have used the OpenComputing Lab to test practical elements of web development. This same approach will be used in the completion of the activities for this week. You will use the development environment provided by the OCL to implement and complete the example scripts outlined here.

## Content in the VCE

Much like the previous activities in this module (weeks 10-13), you will notice a number of folders within your workspace. These folders work in exactly the same way as we discussed in previous sections, but here are the important points:

* {file}`skeletons`: Contains skeleton folders for the activities in Block 3 and TMA03.
* {file}`tma03`: Working area for TMA03
* {file}`work`: Working area for the Block 3 activites.

When you start an activity, you will generally be instructed to copy a folder from the {file}`skeletons` folder
into the {file}`work` folder and then work inside that copy. If at any point during an activity you
feel you have gotten completely stuck and see no way to get it to work, then you can always delete your folder
from the {file}`work` folder and copy it from the {file}`skeletons` folder again.

:::{warning}
Do not edit any of the files in the {file}`skeletons` folder. These will automatically be overwritten
every time you start the VCE.
:::
