# Iteration in Python

When writing a computer program, we often need to perform a single instruction multiple times. We could achieve this by writing the same instruction in our scripts the number of times we need to execute it, but this could prove unwieldy if we need to perform an operation a large number of times. In addition, this does not account for use cases where we may want to perform an instruction or a group of instructions indefinitely. To solve this problem, we use iteration.

Iteration in Python is the process of repeating a set of actions, usually over a collection of items like a list, string, or range of numbers. It’s a key part of programming because it helps automate repetitive tasks. There are a number of ways in which we can employ the concept of iteration all of which depend on the context where we may want to repeat our steps.

The simplest of these, and perhaps the most frequently used, is the {guilabel}`for` loop. This approach to iteration is used in cases where we know how many times we require repetition. An example of this is shown below, where we have an array of fruits with three items. We then follow this with a {guilabel}`for` loop, creating a variable named {guilabel}`fruit` that we use to iterate through the items in the array. In the same manner as we saw with conditionals, we may show relationships between keyword actions and instructions with `:` and the use of indentation.

In this context, an iterator is the temporary loop variable that takes each value in turn as the loop runs. In the example below, {guilabel}`fruit` is the iterator, and {guilabel}`fruits` is the collection being iterated over.

:::{code-block} python
fruits = ["apple", "banana", "cherry"]
for fruit in fruits:
    print(fruit)
:::

An alternative to iterating through the values in a list exists for the {guilabel}`for` loop, where a further function may be used to define a number of times to repeat an instruction: the {guilabel}`range()` function. The {guilabel}`range()` function is used to create a collection of numbers up to a given value. An example of this can be seen in the code below.

:::{code-block} python
for count in range(5):
    print(count)
:::

**Observation**: this prints `0` to `4`, not `1` to `5`. This is because {guilabel}`range(5)` starts at 0 by default and stops before 5.

In the above script, we use the {guilabel}`for` keyword to denote that we want to start a loop. In this statement we also create a temporary variable {guilabel}`count` for the loop. We then see the {guilabel}`range()` function, where we have provided the number 5 to limit the number collection generated by this function. This means that the loop will output the value of the temporary variable 5 times here.

There may be instances where we do not necessarily know the number of times we would like to repeat an instruction. In this case, we can keep repeating while a condition remains true. This incorporates the concepts learned in the conditionals section and iteration. To implement this type of loop, we can use the {guilabel}`while` keyword.

:::{code-block} python
print("Enter some text and press Enter. Enter 'STOP' to finish.")
user_input: str = input("Enter something: ")
while user_input != "STOP":
    print("You entered " + user_input)
    user_input = input("Enter something: ")
:::

In the above example, we create a variable to store the user input. We then use the {guilabel}`while` keyword to repeat the related instructions while the condition remains true ({guilabel}`user_input != "STOP"`). The loop stops once the user types {guilabel}`STOP`, because the condition is then false.
